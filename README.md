# ITZFIZZ scroll experience

A cinematic, scroll-led landing page built with Next.js, Tailwind CSS, and GSAP. The visual direction follows the supplied brief: a dark mountain road, a black sports car, red light trails, a letter-spaced headline, and performance metrics.

## Run locally

Install dependencies with npm install, then start the development server with npm run dev. Open http://localhost:3000 in a browser.

## Three-day build plan

- **Day 1 — Hero foundation:** project setup, visual direction, responsive hero layout, and initial-load reveal.
- **Day 2 — Scroll sequence:** add the pinned, scroll-driven car journey and connect the section progress indicators.
- **Day 3 — Finish and ship:** refine responsive behavior and accessibility, review performance, document the work, and prepare deployment.

Each milestone should be committed after its work is complete so the repository history shows the actual build process.
