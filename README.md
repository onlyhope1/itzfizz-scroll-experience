# ITZFIZZ Scroll Experience

A frontend build based on the car landing-page reference. The page opens on the hero, then moves through four chapters as you scroll.

## Run locally

Install the packages with npm install and start the app with npm run dev. It runs at http://localhost:3000.

## What is in the project

- A full-screen hero with a staggered intro and three impact stats
- A pinned GSAP ScrollTrigger sequence with four chapters
- Clickable chapter controls and a reduced-motion layout

The mountain-road image was made for this project. It uses an unbranded sports car because the reference does not name a specific model.

Responsive and performance polish are the next pass.
